Pseudocode
queue = [start]; visited = {start} while queue not empty: node = queue.dequeue() // process front if node == goal: return path for neighbor in neighbors(node): if not visited: queue.enqueue(neighbor); visited.add(neighbor)

empty
Complexity
TimeO(V + E), visits every vertex once and checks every edge once
SpaceO(V), queue can hold the entire frontier layer simultaneously
Key Insights
  • Core ideaExplores level by level. Because it reaches nodes in order of increasing distance, it guarantees the shortest path in any unweighted graph, DFS cannot make this guarantee.
  • When to useShortest path in unweighted graphs, social network distance (degrees of separation), level-order tree traversal, finding all nodes within distance k.
  • Watch outMemory-intensive. The queue can hold O(V) nodes, a full frontier layer. DFS uses only O(depth) stack space, which is far less for sparse graphs.
