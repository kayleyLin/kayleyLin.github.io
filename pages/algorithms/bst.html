function insert(node, val): if node == null: return new Node(val) if val < node.val: node.left = insert(node.left, val) // go left else: node.right = insert(node.right, val) // go right return node function search(node, val): // similar logic
Values
Complexity
TimeO(h) per operation, O(log n) balanced tree, O(n) degenerate/skewed tree
SpaceO(n) for n nodes, O(h) extra for recursion stack during traversal
Key Insights
  • Core ideaEvery node satisfies: all left descendants < node < all right descendants. This single invariant makes search O(h) and in-order traversal always produce sorted output.
  • When to useDynamic sorted sets with frequent insert/delete, database index structures (B-trees are generalisations), implementing ordered maps and priority queues.
  • Watch outInserting already-sorted data creates a linked list, O(n) height, O(n) operations. Production code uses self-balancing variants: AVL trees or Red-Black trees maintain O(log n) height automatically.
