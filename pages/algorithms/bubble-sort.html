Pseudocode
for i in range(n - 1): for j in range(n - i - 1): if arr[j] > arr[j+1]: swap(arr[j], arr[j+1]) // rightmost i+1 elements sorted

Complexity
TimeO(n²) worst/average, O(n) best case if early-exit flag detects sorted input
SpaceO(1), sorts in-place, no extra memory needed
Key Insights
  • Core ideaAfter each full pass, the largest unsorted element is guaranteed to be in its final position. The sorted boundary grows from the right.
  • When to useAlmost never in production. Useful for teaching swap mechanics and the concept of loop invariants.
  • Watch outDespite the O(n) best case, insertion sort is faster in practice on nearly-sorted data due to fewer comparisons and better cache behaviour.
