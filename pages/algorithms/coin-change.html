Analogy

Making exact change at a register, what's the fewest coins to reach this total?

Pseudocode
dp = [∞] * (amount+1); dp[0] = 0 for i in range(1, amount+1): for coin in coins: if i >= coin: dp[i] = min(dp[i], dp[i-coin] + 1) // dp[amount] = minimum coins needed
Complexity
TimeO(amount × |coins|), for each of the amount+1 values, tries every coin denomination
SpaceO(amount), a single 1D array from 0 to target amount
Key Insights
  • Core ideaBuild solutions bottom-up: dp[i] = minimum coins for amount i. Each value reuses previously computed smaller values, no work is repeated.
  • When to useA template for "minimum steps to reach a goal" problems. Generalises to word break, jump game, stair climbing, any problem where you pick from a set of fixed-size steps.
  • Watch outGreedy fails here. With coins [1, 3, 4] and amount 6: greedy picks 4+1+1 = 3 coins. DP finds 3+3 = 2 coins. Always verify whether greedy gives the global optimum before skipping DP.
