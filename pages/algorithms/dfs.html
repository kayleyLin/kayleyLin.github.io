Complexity
TimeO(V + E), every vertex and edge visited exactly once in a complete traversal
SpaceO(V) stack depth worst case, O(depth) for typical trees and sparse graphs
Key Insights
  • Core ideaGoes as deep as possible along each branch before backtracking. Naturally produces a DFS tree where back edges indicate cycles.
  • When to useCycle detection, topological sorting (reverse post-order), finding strongly connected components (Kosaraju/Tarjan), maze solving, generating permutations.
  • Watch outOn cyclic graphs, must track visited nodes or DFS loops forever. Deep recursion can cause stack overflow, iterative DFS with an explicit stack avoids this.
