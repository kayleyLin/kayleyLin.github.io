Key Insights
  • Core ideaA greedy algorithm that works because edge weights are non-negative: once a node is extracted from the priority queue with distance d, d is provably optimal. No future path can be shorter.
  • When to useGPS routing, network packet routing, flight path optimisation, any single-source shortest path problem with non-negative edge weights.
  • Watch outFails with negative edges, a cheaper path could be discovered after extraction. Use Bellman-Ford for negative weights (O(VE), slower but correct).
