Pseudocode
function fib(n): if n <= 1: return n if memo[n] exists: return memo[n] // memoized memo[n] = fib(n-1) + fib(n-2) return memo[n]
Complexity
TimeO(2ⁿ) naive → O(n) memoized. fib(40) naive ≈ 1 billion calls; memoized = 40.
SpaceO(n) for memo table; O(n) call stack depth
Key Insights
  • Core ideaOverlapping subproblems make naive recursion exponential. The same fib(3) is computed dozens of times. Caching one value changes the entire complexity class.
  • When to useThe gateway DP problem. Master the memo pattern here and Knapsack, LCS, Coin Change all become variations on the same idea.
  • Watch outThe exponential blowup is invisible for small n. Try computing fib(50) without memoization; it will hang.
