Analogy

Moving rings by one rule is the simplest possible recursion, it writes itself.

Pseudocode
function hanoi(n, from, to, aux): if n == 0: return hanoi(n-1, from, aux, to) // move n-1 out of way move disk n: from → to // move the big disk hanoi(n-1, aux, to, from) // stack n-1 on top
Complexity
TimeO(2ⁿ), n=4 needs 15 moves; n=30 needs over a billion
SpaceO(n), one stack frame per recursion depth
Key Insights
  • Core ideaThe n−1 sub-problem must be solved twice, once to expose the bottom disk, once to rebuild on top. There is no shortcut.
  • When to useThe canonical example for teaching recursion. The algorithm structure IS the proof of correctness, no iterative version is more intuitive.
  • Watch out2ⁿ growth is brutal. n=64 disks would take longer than the age of the universe to complete at one move per second.
