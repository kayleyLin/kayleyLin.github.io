Analogy

Sorting cards in your hand, pick one up, slide it left until it's in the right place, repeat.

Pseudocode
for i in range(1, n): key = arr[i] j = i - 1 while j >= 0 and arr[j] > key: arr[j+1] = arr[j]; j -= 1 arr[j+1] = key // insert key

Complexity
TimeO(n²) worst case, O(n) best case on already-sorted input
SpaceO(1), in-place. The sorted left partition grows without extra memory.
Key Insights
  • Core ideaMaintains a sorted "left half" at all times. Each new element slides leftward until it finds its place, like inserting a card into a sorted hand.
  • When to useJava's Arrays.sort uses insertion sort for arrays smaller than 47 elements. Excellent for nearly-sorted data and as the base case in hybrid sorts (Timsort).
  • Watch outPeople underestimate it. For n < 20, insertion sort often beats quicksort due to minimal overhead and excellent cache locality.
