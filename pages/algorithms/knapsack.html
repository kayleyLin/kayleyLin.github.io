Analogy

Packing a suitcase with a weight limit, what combination of items gives the most value?

Press Play or Next to begin.

Pseudocode
for i in range(1, n+1): for w in range(0, W+1): if items[i].weight > w: dp[i][w] = dp[i-1][w] // can't include else: dp[i][w] = max(dp[i-1][w], items[i].val + dp[i-1][w-wt])
Complexity
TimeO(nW), pseudo-polynomial. Fast when capacity W is small; impractical when W is huge.
SpaceO(nW) for 2D table, reducible to O(W) using a single rolling 1D array
Key Insights
  • Core ideaOptimal substructure: the best solution for capacity W using items 1..i contains the best solution for a smaller subproblem. Each item is a binary choice: include or exclude.
  • When to useResource allocation, investment portfolio selection, cargo loading, cutting stock problems, any scenario with a budget and items of varying weight/value.
  • Watch outThis problem is NP-Hard in general. O(nW) only works because W is treated as a numeric value, not its bit-length. For large W, approximation algorithms are needed.
