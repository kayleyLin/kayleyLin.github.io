Pseudocode
for i in range(1, m+1): for j in range(1, n+1): if X[i-1] == Y[j-1]: dp[i][j] = dp[i-1][j-1] + 1 // match else: dp[i][j] = max(dp[i-1][j], dp[i][j-1]) // traceback from (m,n) to find actual LCS
Complexity
TimeO(mn), fills every cell of the m×n DP matrix exactly once
SpaceO(mn) for full matrix, reducible to O(min(m,n)) if only the length is needed
Key Insights
  • Core ideaIf characters match, extend the diagonal (previous LCS + 1). Otherwise, take the best of skipping either character. The table encodes all possible alignments simultaneously.
  • When to usegit diff (finding what changed between files), DNA sequence alignment, spell checking, file comparison tools, and version control systems all use LCS at their core.
  • Watch outLCS ≠ longest common substring. A subsequence can skip characters; a substring must be contiguous. "ABCD" and "ACBD" have LCS length 3 but no common substring longer than 1.
